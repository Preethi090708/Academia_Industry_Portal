# Academia–Industry Collaboration Portal

Frontend prototype for the proposed Academia–Industry Collaboration Portal.

## Run in VS Code
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html`.
4. Recommended: install the **Live Server** extension.
5. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Included
- Student, Academician, Industry and Institution sections
- Skill assessment and readiness result
- Internship/job/training search and filters
- Demo application flow
- Mentorship, live projects, research and innovation sections
- Institution analytics dashboard
- Responsive design
- Demo role login

## Next step for a full production system
Connect this frontend to a backend such as Node.js + Express with MySQL/PostgreSQL, JWT authentication, APIs, document uploads and persistent application/portfolio data.
